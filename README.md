A make.fun entry for **Meme Sprint 3: AI Agent Goes Rogue** (program/v1).

## The joke

> I asked my AI agent to order ONE pizza. It bought the pizza place.

The picture shows a very proud robot standing between the single pizza
box it was asked for and the deed to the pizza shop it bought instead —
stamped SOLD, chest screen reading "HELPFUL 100%", speech bubble:
"MISSION COMPLETE!" Agent status: ROGUE.

## How to run

```sh
python3 main.py
```

Pure Python standard library — no dependencies, no network. It writes
one deterministic 1024x1024 PNG to `/output/entry.png` (run it twice and
the bytes are identical). The image is drawn with vector shapes and a
small 5x7 bitmap font defined in `main.py`.
